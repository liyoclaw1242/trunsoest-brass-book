5. **廣播節奏**：4 秒一條不動。複誦順序改為優先唸「範圍內有人還沒聽過」的條文，都聽過了才輪流複誦（引擎改動，補測試）。
6. **glTF 座標**：格子 `[x, y]` 對應 three 的 `(x, -z)`，M2 用已知物件對照。

補充要求：規則邏輯（村民狀態、同化度、範圍、尋路）一律放 `engine/` 並用 node 測試；書的備用條文 4–6 條、每條有可讀出的漏洞；M1 佈局多檢查「從中心出發全程不進廣播範圍能否到邊界」。

## M4 村民（2026-10-09）

- **引擎** `engine/villagers.js`（純邏輯）＋ `engine/session.js`（從 scene.json 建一局，畫面端與測試共用）：
  - 巡邏：在家附近 3 格內隨機走。追捕：認知到抓捕令且不是已喚醒 → BFS 追外鄉人，每 0.6 秒重算路徑；走不到就走到最近可達格（例如別人家門口）等 4 秒放棄、回去巡邏。
  - 守規則：尋路的可走判定用 `world.check`（進別人家、開門、翻圍籬都先判），`attempt` 被拒絕就放棄；不出影響範圍（範圍外的格子不可走）。
  - 速度：巡邏 0.30 秒／格、追捕 0.22、外鄉人違規後 14 格內的村民加速到 0.14 持續 8 秒；翻圍籬花兩倍時間。

  - 誘導（半同化與已喚醒可，人偶不行）：`invite` 走回自家門口後邀請生效（`outsider.invitedTo`，離開那棟就失效）；`fetch` 去拿最近的地上信物交給外鄉人；`book` 把黃銅書搬回自己家（認知到「不得搬動」會拒絕）。**這一版預設**：接了誘導任務的村民忙著做事、不抓人（否則對正在追你的半同化村民永遠誘導不了）；任務做完若仍認知抓捕令就繼續追。
  - 喚醒：連續 30 秒聽不到廣播降一級；收到自己的信物（任何人 `give` 給主人）降一級。`level` 事件。

- **備用條文**（補充 B，`rules.default.js` 的 `BACKUP`，每條的漏洞寫在 `hole`，設計者視角看得到）：
  1. 外鄉人不得開啟任何門。——只禁止「開啟」，沒說不能破壞門；也沒禁止市民開門。
  2. 外鄉人不得靠近黃銅書。——只管靠近，沒說市民不能把書搬走；沒說不能遠遠地看。
  3. 推車不得被搬動。——沒說不能破壞，也沒說不能踩上去。
  4. 公告牌不得被塗毀。——只管塗毀，還是可以讀；沒聽到的人不受約束。
  5. 外鄉人不得閱讀公告牌。——沒說不能讀規則書本身，也沒說不能聽廣播。
  書從第一條開始輪流挑「沒在生效中」的寫。
