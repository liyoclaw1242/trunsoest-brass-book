# round-2 材料

第 1 輪之後的版本（誘導 20 秒冷卻、書台住宅兩台廣播器覆蓋、備用條文 10 條、重置閃現列全文、村民被規則擋住的回饋）。

- `keepsake/`：won/escaped，64.5 秒，被抓 1 次，喚醒 3 人，書寫 1 條，重置 0 次。
- `book/`：won/escaped，48.5 秒，被抓 1 次，喚醒 1 人，書寫 2 條，重置 0 次。
- `deaf/`：lost/assimilated，64.9 秒，被抓 3 次，喚醒 2 人，書寫 2 條，重置 0 次。

路線說明見 `HOW_TO_RUN.md` 與 `tools/playtest.js` 開頭註解。三條路線共用開場：聽完公告 → 砸掉廣場的廣播器 → 進書台屋躲過 8 秒加速、隔著門把屋主支開 → 轉移到已喚醒村民 04 的家。
- keepsake：誰到門口就請他去拿信物，信物還給主人喚醒；沒人追（醒了或在跑腿）就走出範圍。
- book：等書台屋主到門口，請他把書搬回他家；範圍圓心一移，藏身處就在範圍外。
- deaf：趁空檔衝出去砸其他廣播器讓村民因安靜而醒。這條在第 1 輪加了誘導冷卻之後衝不出去，連跑幾次都在範圍內被抓三次；保留當資料。

每個資料夾：`events.txt/json`（事件紀錄）、`rulebook.txt`/`rules.json`（規則書：條文、是否撕掉、誰認知、漏洞）、`summary.json`、`NN-*.png`（關鍵時刻截圖）。
