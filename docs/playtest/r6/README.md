## 平衡檢查（`node tools/balance.js`，見 balance.txt）
- **什麼都不做**：全村工作時活性約 **16.7 分鐘**到頂 → 被轉化。每喚醒一人延長並降低規則上限：5 人 20 分、4 人 25 分、3 人 33 分、2 人 50 分。活性是停不住的後盾，所以每一局一定會結束（沒有無解／跑不完的局）。
- **全程躲在聽不到廣播的地方**：同化度會退，但活性照漲（時間×勞動比例）。只躲不喚醒村民，最後仍輸給活性——躲藏本身不是出路，要搭配罷工或封印。
- **前期硬闖邊界**：開場「不得越過界石」生效時邊界封印，走不出去（`sealed`）。第一次重置撕掉整組憲法才打開逃跑窗口；書會花書寫時間重寫邊界條文把它封回去，所以窗口有限、且越後期書寫越快窗口越短。要逃必須在窗口打開時已靠近邊界（engine 實測：站在內緣、重置開窗、踏出一步＝逃跑）。
- **單一必勝策略**：沒有。逃跑要卡窗口與位置；封印各有前置（喚醒／搬書到荒野／毀書要村民護不住）；硬衝被封印擋住。
- **重現性**：同種子兩次完全相同（`rules.v2.test.js`）。

## 推薦先試的種子
任意種子都可玩；`r6win`、`r5*` 可對照。逃跑要配合第一次重置的窗口。
