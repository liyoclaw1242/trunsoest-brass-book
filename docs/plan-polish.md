# P1 體驗與品質（玩家試玩反饋）

反饋：初期不知道做什麼；故事與介紹不足；UI 不夠商業品質。使用者決定：引導做「明確目標＋逐步提示」；品質提升「連 3D 場景美術一起升級」。

## P1a 引導 ＋ HUD 質感
- 常駐「目前目標」一行，依狀態更新（聽規則 → 認識兩個時鐘 → 喚醒村民／等重置空檔逃出 → …）。
- 逐步情境提示：開場、第一條規則、靠近村民、第一次重置、第一次被抓、活性進階段，各出現一次後淡出，記住不重複。
- HUD 全面重做：字體、排版、間距、配色系統、量表設計（活性階段分區、同化度 5 格）、toast 動態、書寫橫幅、廣播面板、筆記面板。

## P1b 3D 場景美術
- three.js：更好的光（方向光＋補光＋陰影）、色調映射、霧、地面質感、陰影柔化。
- Blender：principled 材質、圓角與層次、屋頂與建築細節、整體配色統一。程式生成，不手動建模。

## P1c 開場敘事 ＋ 開始／結局畫面
- 開場：循環村子、你是下一個路過的人、入口的放逐痕跡——動畫式或分段文字。
- 開始／結局畫面排版到商業水準。

每塊：截圖自評、commit、changelog。設計不改已定案機制，只改呈現與引導。
