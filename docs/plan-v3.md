# 原型三 執行計畫

目標：在原型二的基礎上，把方向改成「違規被看見才追」「不得離開是憲法、重置才有出口」「晝夜」「偽裝」，地圖加大。素材品質不管。

## 這一版要驗證什麼

1. 沒有抓捕令時，壓力是否仍然存在（只靠「被看見違規」）。
2. 「不得離開」撕掉的窗口是否看得出來、抓得住。
3. 晝夜是否改變玩家的選擇（夜間違規沒人廣播、沒人看見，但看不見路）。
4. 偽裝是否成為真正的取捨（穿了不容易被認出，但穿衣本身是違規）。
5. 原型二的 1–5、8 在大地圖上是否仍成立。

## 里程碑

- **V1 引擎**：時鐘與晝夜、條件（night/day/lit/wearing/inhouse/zone）、新動詞（leave/walk/run/wear/light）、v3 條文、不得離開＝傳送、目擊追逐、夜間靜音、偽裝與辨識、提燈、睡覺與守夜。測試覆蓋每一項。驗收：`npm test`。
- **V2 場景**：100×100、半徑 32、6 棟住宅與村民、村道／野地分區寫進 scene.json、燈柱、晾衣繩與衣物、提燈、崗位。驗收：validate、check-layout（加分區檢查）、兩張圖。
- **V3 畫面**：晝夜光照與夜間變暗、時鐘 HUD、視線圈（設計者視角）、偽裝與持燈狀態、「被看見違規」的回饋、傳送回中心的演出、窗口（不得離開失效）的提示。驗收：腳本重現每一項並截圖。
- **V4 試玩**：兩條路線（例如「逼書寫滿十條，在窗口衝出去」「夜間偽裝摸到邊界等天亮前的重置」），人工檢查什麼都不做、直奔、躲屋。更新 CLAUDE.md、SUMMARY。

每個里程碑：npm test、commit、changelog。觸及已定案的問題寫 open-questions。
