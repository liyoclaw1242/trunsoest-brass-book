# 改版 v2 總結（2026-01）

外鄉人誤入一個烏托邦，一本靠村民勞動過活的活規則書要把他也變成村民。他要在被轉化前找到出路（逃跑或三種封印）。這一輪依 `docs/design.md` v2 重做，R0–R6 加三輪優化全部完成。

## 怎麼啟動

```
npm install          # three / vite / @playwright/test，只裝本專案
npm run dev          # http://localhost:5173/
```

開始畫面可輸入種子（或網址 `?seed=<種子>`）。WASD／方向鍵移動、Shift 奔跑、E 互動（數字鍵選其他動作）、N 筆記、Tab 設計者視角。

- `npm test`：引擎 37 項＋條文驗證。
- `node tools/playtest-r5.js`（五結局）、`r3`（介面）、`r4`（經濟）、`node tools/balance.js`（平衡）、`node tools/round-capture.js <種子>`（跑一局存材料）。
- 設計：`docs/design.md`、條文池 `docs/rule-pools.md` 與 `engine/rules.v2.js`、計畫 `docs/plan-v2.md`。歷史：`docs/design-v1.md`、`design-v3.md`。

**推薦先試的種子**：任意皆可玩。`r5*` 可對照五結局、`round3`／`alpha`／`beta` 是優化回合的試玩種子。種子決定書「寫得多嚴」的骰子，同種子完全重現。

## 八個驗證目標

| # | 目標 | 結果 | 依據 |
|---|---|---|---|
| 1 | 機率像有狀態的對手、不是運氣；前期抽嚴謹來得及反應 | **大致成立；真人未判定** | 20 種子抽樣前三抽出現嚴謹僅約 7%，前期多粗糙；draw 現在偏好與你行為相符的條文，因果讀得出。但「有狀態 vs 更慢的隨機」要真人樣本。 |
| 2 | 看得懂兩個時鐘（同化度管得了、活性停不下來） | **成立** | 左上活性量表＋階段界標、同化度量表、活性每次變動有文字理由（補漏洞／撐重置／村民罷工／隨時間）。`docs/playtest/r3/`。 |
| 3 | 看得出勞動流向書、喚醒讓書變弱 | **成立** | 村民生產→送進圖書館（120 秒 37 次）；喚醒三人規則上限 10→? 下降、活性增速 +1.7→+0.7/22s。 |
| 4 | 舒適的誘惑有吸引力、事後發現代價 | **部分成立；真人未判定** | 四項好處都接上（名字＝不被主動追、衣服＝相鄰才認得出、房子＝可進、工作＝可換物但也餵養書）；代價（對上定義類）要後期才踩到。吸引力強弱要真人。 |
| 5 | 逃跑前期做不到、中後期出窗口、越後期越短 | **成立（窗口很緊）** | 封印需公示、開場即被告知「不得越過界石」；窗口＝第一次重置撕掉它到書重封的書寫時間，後期書寫更快窗口更短。要在窗口內已靠近邊界（engine 實測）。 |
| 6 | 定義類造成「大家當你市民、你不能聽到那句話」 | **部分成立；真人未判定** | 定義雙效果引擎成立（符合且認知到→同化到頂；村民認知到→當你市民不追）；後期有定義偏置、10 秒書寫窗口。但要活性≥70 且符合某定義，實玩到後期不易。 |
| 7 | 各結局都做得到、代價看得出 | **成立** | `playtest-r5.js` 6/6（五結局，含被轉化的活性／同化兩觸發）；結局畫面列種子、用時、書寫、重置、活性最高、被抓、每個村民下場。放逐這版補上代價（損毀已移除）。 |
| 8 | 舊的沒壞（規則指向物件、公示才生效、重置後恢復可破壞） | **成立** | `engine/engine.test.js`（原型二驗收）保留並通過；公示才生效在「封印需認知」上也修正到位。 |

## 五種結局

| 結局 | 做得到？ | 備註 |
|---|---|---|
| 被轉化（輸） | 是 | 同化度 5 或活性 100，兩種觸發都實測。 |
| 逃跑 | 是 | 走出範圍且村裡還有未喚醒村民；要卡重置窗口＋靠近邊界。 |
| 空村（封印一） | 是 | 走出範圍時範圍內已無未喚醒村民。 |
| 放逐（封印二） | 是（機制） | 書被放下在荒野深處、附近無村民。親自搬書每 20 秒同化度 +1、步速慢；用山羊馱較划算。真人走完這條路未驗。 |
| 無人聆聽（封印三） | 是 | 無完好廣播器、無可讀公告牌、≥3 人喚醒留村、60 秒無新認知。 |
| ~~損毀（封印四）~~ | 已移除 | 使用者移除隕石魔法書設定，此結局取消。 |

五種（被轉化、逃跑、空村、放逐、無人聆聽）用固定種子的腳本達成（`playtest-r5.js` 6/6，被轉化含兩種觸發）。放逐的「真人正常遊玩能否走完」未用真人驗證。

## 調過的數值（起點 → 現值，為什麼）

- 村民開場同化程度：原 villager_04 開場已喚醒（上限 9）→ 全部未喚醒（上限 10），否則第一次重置留得住「不得越過界石」、逃跑窗口打不開。
- 重置保留數：固定 5 → `null`（依浮動上限 `ceil(max/2)`）；撕 0 條不算重置。喚醒村民後上限下降時才正確。
- 書寫時間：粗糙 2／普通 4／嚴謹 10 秒（×活性係數）；定義類一律 10 秒（給反應窗口）；邊界重封固定 4 秒基底（與等級脫鉤，後期才真的更短）。
- 發現漏洞機率、活性權重、活性增減：沿用 design 預設（20%＋活性×0.6%、第 5 次必中；0→70/25/5、50→35/45/20、100→10/35/55；時間 +1×勞動／10 秒、補漏洞 +3、重置 +5、抓到 +2、喚醒 −4）。
- 搬書步速 0.6 秒／格（放逐要付時間代價）。
- 移除隕石魔法書與損毀結局（使用者試玩後決定）。
- 界石 `approach`／進野地 `enter` 各 30 秒去重（擋裝聾在界石旁 farm 逼寫重置）。
- 晝夜：v2 關閉（原型三殘留）。

## 三輪評論員說了什麼、怎麼處理

每輪先對整池跑 `audit-rules`，再用 `playtest-critic`。只給它執行方式與材料，不給我的評價。

- **第 1 輪**：封印無視公示（打破「公示才生效」）→ 改成需認知、開場公告；舒適只有名字兌現 → 四項好處全接上；活性跳動無解釋 → 加文字理由；放逐／損毀零代價 → 隕石引信＋死亡、放逐 +1/20s；定義類接線、書在階段門檻主動寫。
- **第 2 輪**：圖書館進不去、勞動沒流動 → 書台移出入口格（實測送得進去）；裝聾在界石旁 farm 零風險逃跑 → approach 去重；放逐／損毀仍太便宜 → 搬書變慢、隕石移進範圍、放逐要「放下」才算；「看見你違規」誤報 → 分出 `spotted`；舒適選單與房子／工作好處。
- **第 3 輪**：目擊用行為者自己的認知 → 裝聾者永遠「沒違規」、「名字＋裝聾」70 秒繞過全機制 → 改用**旁觀村民的認知**判定（裝聾砸廣播器照樣被認知該條的村民追）；重置保留數固定 5 的 bug → 依浮動上限；定義類即寫即唸無窗口 → 10 秒書寫；傳染觸發不了 → 改判定時機；書補你沒用的漏洞 → draw 偏好相符條文；speaker／well／fence 鏈真的升級（第 2 輪宣稱但遺失，這輪補上）。

每一項的分類（這輪改／預設調整／寫進 open-questions／不採納）與證據在 `docs/changelog.md` 的三段「優化回合」。

## 等你決定的問題（`docs/open-questions.md`）

- **義務類 `require` 的非遵從強制**：引擎只對 forbid/permit 算違規，「應……沒做＝違規」沒有通用判定；中期義務目前只有「照做＝接受舒適」一半有後果。需要一個義務檢查器。
- **社交動詞不做對話**：talk／greet／listen／invite 本版不做，對應條文是陳列品；`d-greeted` 因此是死條。要不要為它們加最小互動。
- **`stay` 動詞未接線**：`s-broadcast-stay`、`o-curfew`、`h-stay-indoors` 判不到。
- **工作「換到物品」**：目前只有勞動代價，無物品產出。
- 另有數條「文字比動作大」的條文（`a-fence-both` 已修；`s-notice-*`／`p-book-touch` 文字提到的動作引擎沒開放），列在 open-questions。

## 我沒驗證到的部分

- **真人手速與節奏**：腳本能在被抓前 0.5 秒接受名字、在 4 秒廣播內跑出 25 格；真人做不做得到，決定「舒適誘惑」「聽不聽是抉擇」「後期即死」實際成不成立。三輪評論員都點出這點。
- **放逐（牽山羊馱書）的真人走法**：腳本沒驅動牽羊整條路線，實玩能否走完未由真人確認。
- **後期的「大家當你市民」局面**：需要不用 `setActivity`、真人玩到 10 分鐘後期才看得到。
- **平衡的全村模擬**：20 種子的全村尋路模擬在 100×100 太慢，改用純模組快轉量測；真實對局的結局分布未大量取樣。
- 評論員是子代理（前兩輪用 general-purpose＋原樣指令，第三輪 session 已認得 `playtest-critic`），非真人玩家。
