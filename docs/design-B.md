# 改版方向 B：鑽規則漏洞（Rules Lawyer）

使用者試玩後覺得不好玩。診斷：現在是「閃避＋等待」的計時器，玩家沒有有意義的主動選擇；核心賣點「書立法」沒逼出有趣取捨。選定方向 B：把它做成**潛行解謎**——每條法是一道限制，樂趣在於**讀懂法、鑽它的破綻、逼它自相矛盾、趁它重寫脫身**。你比書聰明。

## 為什麼 B 貼題又可行

書本來就會「立法綁你、你鑽漏洞、它補漏洞」。引擎其實已經有全部素材：

- 每條候選條文都寫了 `hole`（破綻），而且多半是遊戲內可執行的（搬界石、讓山羊馱書、沒聽到就不受約束、滿足定義變市民、等重置）。
- 公示才生效：沒聽到的法不綁你（`known` 判定）。
- 矛盾會觸發裁決：認知到的「不得」與「得」衝突 → `writeRuling`，當下不追究。
- 重置會撕掉憲法（含界石封印），留下脫身窗口。
- 書會因應你的行為立法、鑽了會補更嚴的版本（階級升級）。

缺的是**可讀性、回饋、誘因**，不是模擬本身。

## 核心循環

1. 書觀察你 → 立法限制你（每條都有破綻）。
2. 你讀法（公告牌／廣播／筆記）→ 筆記列出每條法與它的**破綻**。
3. 你鑽破綻：搬界石、讓山羊馱書、裝聾讓法不綁你、誘導村民或山羊代勞、逼出矛盾、趁重置窗口。
4. 書發現你鑽 → 補破綻（寫更嚴的版本）。貓捉老鼠式升級。
5. 用這些手段脫身。

## 輸贏

- **輸（逼你主動）**：活性到 100（太被動、拖太久，書立法立到活過來）或 同化度到 5（照它的法生活被同化）。被動一定輸。
- **贏**：逃跑（趁破綻／重置越界）、放逐（用破綻把書弄到荒野）。
- **（下一步可加）癱瘓書**：逼出夠多矛盾／讓書無法可立 → 權威崩潰、封印失效，直接走出去。這會是最純粹的「鑽漏洞」結局。

## 玩家的動詞（B 的樂趣來源）

- **讀法**：知道法才找得到破綻（但知道也會被它綁——張力）。
- **鑽破綻**：情境動作（搬界石、馱書、取水而非藏身……）。
- **製造矛盾**：做同時被「禁」與「准」涵蓋的事 → 裁決，累積可癱瘓書。
- **裝聾／遮蔽**：讓某條法不綁你，或不綁村民。
- **代勞**：誘導村民或山羊做只綁外鄉人的事。

## v1（這一輪先做，低風險、先讓人感受到方向）

1. **法典面板（Law Ledger）**：筆記裡每條「已聽到」的法，列出它的**破綻**，並標出「現在就能鑽」的。
2. **目標重寫**：從「躲好等窗口」改成「讀懂書的法、鑽破綻脫身」。
3. **鑽到破綻的回饋**：逼出裁決、用山羊馱書、趁重置越界等，給明確 toast 與紀錄；逼出矛盾時活性小幅回退（主動玩有回報），書隨後補破綻。
4. 確保兩條脫身路徑（重置衝界、山羊馱書放逐）在新框架下清楚可玩。

## 已暫定的決定（待驗證）

- **破綻直接顯示**（不先藏起來）：先讓漏洞循環立刻好讀、好玩；日後可改成「研讀某條法才顯示它的破綻」當作一層解謎。
- **保留現有輸贏與兩條脫身路徑**；「癱瘓書」結局等 v1 手感驗證後再做（較大、動到 match 的輸贏經濟）。
- 喚醒已移除，不復活；B 的反擊改用「鑽法律漏洞」取代。

## 之後要驗證的

- 真人玩起來，「讀法→找破綻→鑽過去→被補→換下一個」這個貓捉老鼠是不是好玩。
- 誘因是否真的逼人主動（被動會輸、主動有回報），而不是又變成裝聾擺爛。
