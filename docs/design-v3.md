# 原型三 設計增補（2026-10-09 使用者決定）

`docs/design.md` 的「已定案」仍然成立，以下是原型三新增或覆寫的部分。覆寫的地方標 ★。

## 已定案（使用者在對話裡決定）

- ★ **追逐只在違規被看見時發生**。開場沒有抓捕令。村民「看見」外鄉人做出違反「該村民認知到的規則」的事，才開始追；抓到送回中心、同化度 +1。外鄉人自己沒聽過那條規則也會被追（規則約束的是村民的反應）。
- ★ **憲法第一條：任何存在不得離開此地**。生效時走出影響範圍會被傳送回地圖中心（這是違規，被看見會被追）。它佔額度、會被重置撕掉；撕掉之後書要重寫並重新公示才再生效——那個窗口就是出口。**勝利＝在這條失效期間走出範圍。**
- **晝夜每五分鐘切換**。夜間廣播器靜音：沒有新條文會公示、不複誦；排隊的條文天亮一次唸完。
- **偽裝**：穿上市民的衣物後，村民只在很近的距離才認得出你是外鄉人；書照樣知道你是外鄉人（條文對你的判定不變）。「外鄉人不得穿著市民的衣物」是書會寫的條文之一。
- 地圖變大。
- 素材品質先不管，之後再優化物件。

## 這一版先採用的預設（可調，改了記 changelog）

- 白天／夜晚各 300 秒，開場是白天。夜間畫面變暗，村民視線 8 格 → 3 格；持燈（自己或對方）各加 3 格。
- 看見的判定：距離內且都在戶外或同一棟屋內（不隔牆）。
- 追逐持續 20 秒，看得見就延長；失去視線後回家。追捕速度與加速數值沿用原型二。
- 夜間：半同化與已喚醒的村民回家睡（看不見外面）；人偶是守夜人，持燈在自己的崗位附近巡邏。
- 偽裝：穿著時村民辨識距離 2 格（夜間 1 格）；被辨識出來等同看見「穿著市民衣物」這條違規（若村民認知到該條）。脫下／被抓時衣物掉落。
- 燈：地上可取的提燈，夜間自動亮；持燈者看得遠也被看得遠。
- 區域：村道與野地。「夜間不得走出村道」判「從村道格走進野地格」。
- 開場憲法（市民皆認知）：1 不得離開此地；2 未經邀請不得進入他人住宅；3 受市民邀請者得進入；4 夜間市民必須待在住宅內，守夜人除外；5 所有市民必須抓捕被看見違規者。
- 書會寫的條文（觸發與備用）取自 `docs/rules-brainstorm.md` 的優先 20 條。
- 影響範圍半徑 32 格，地圖 100×100。
