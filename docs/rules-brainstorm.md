# 規則腦力激盪（原型三方向）

依 2026-10-09 的新方向整理：
- 村民**違反規則時才追**（看見外鄉人違規 → 追；不再一開場就全村抓人）。
- 開場就有一條「**任何存在不得離開烏托邦**」，走出去會被傳送回地圖中心。
- 地圖更大；**晝夜每五分鐘切換**。

先列規則，再從規則反推要做哪些物件。每條格式：

> **條文** ｜ `who / verb / target / cond / mode` ｜ 漏洞（從文字就讀得出來的那個） ｜ 需要的物件或機制

`who`：any 任何存在、citizen 市民、outsider 外鄉人、puppet／half／awake 各種村民（新）。`cond`：night 夜間、day 白天、seen 被看見、invited、lit 持燈、wearing 穿著…（新的都標 ★）。
`mode`：forbid 不得、permit 得、require 必須。

## 0. 先想清楚的幾件事（規則怎麼寫取決於這些）

1. **勝利條件怎麼改**。「不得離開」如果是撕不掉的底層規則，就永遠贏不了。我的建議：它是**憲法第一條**，佔額度、會被重置撕掉。重置的瞬間它失效，書要重寫並重新公示（4 秒）才再生效——那幾秒就是逃出去的窗口。重置從「雙面刃」變成「唯一的出口」，整個遊戲變成「逼書寫滿十條」。另一個選項：書活過來之前它永遠生效，贏法改成「把書搬出範圍」或「讓所有村民醒來」。這要你決定。
2. **追逐的觸發**。建議：村民 **看見**（視線＋距離）外鄉人做出違反「該村民認知到的規則」的事 → 追 N 秒（例如 20 秒）或直到失去視線＋10 秒；抓到＝傳送回中心＋同化度 +1。外鄉人自己沒聽過那條規則也會被追（規則約束的是村民的反應，不是玩家的認知）。這和原本「違規後 8 秒加速」合併。
3. **夜晚改變什麼**。建議三件：(a) 視線短（村民看得近，玩家畫面也暗）；(b) 村民回家睡（人偶不睡，站崗）；(c) 一組只在夜間生效的條文（cond: night）。廣播器要不要夜間休息、公告牌看不看得見，是可調的預設。
4. **地圖變大之後的「中心」**。傳送回中心＝回到書台前。地圖大了，被傳送回去就是很大的懲罰（走回邊界要很久），所以追逐不能太容易抓到人。

## A. 憲法候選（開場就在書裡、市民皆認知；挑 4–6 條）

1. **任何存在不得離開此地。** ｜ `any / leave★ / boundary / – / forbid` ｜ 沒說不能「被搬出去」（躺在推車上？）；重置撕掉就能走 ｜ 界石、傳送回中心
2. **此地不為外界所知。** ｜ 敘事條文 ｜ 佔額度，撕掉也沒差——除非「外界」有人來（信差、商隊）
3. **不得傷害他人。** ｜ `any / harm★ / villager|outsider / – / forbid` ｜ 「他人」包不包括人偶？推倒不算傷害？ ｜ 若有推／絆倒動詞
4. **未經邀請不得進入他人住宅。** ｜ `any / enter / house / uninvited / forbid` ｜ 受邀得進入（第 5 條）；「住宅」不包括倉庫、教堂、井屋 ｜ 非住宅建築
5. **受市民邀請者，得進入該市民的住宅。** ｜ `any / enter / house / invited / permit` ｜ 和後來的「外鄉人不得進入住宅」衝突 → 裁決
6. **夜間所有市民必須待在住宅內。** ｜ `citizen / stay★ / house / night / require` ｜ 只管市民；外鄉人不算；人偶算不算市民 ｜ 晝夜、村民睡覺行為
7. **市民不得與外鄉人交談。** ｜ `citizen / talk★ / outsider / – / forbid` ｜ 已喚醒者算不算市民；外鄉人先開口算誰的 ｜ 誘導＝交談的一種
8. **廣播所言即為律法。** ｜ 敘事 ｜ 撕掉也沒差，但撕掉那一刻「公告牌」是不是還算公示？（可做成：撕掉後公告牌失效）
9. **黃銅書不得被任何存在觸碰。** ｜ `any / touch★ / book / – / forbid` ｜ 用推車推、用布包、請人搬——「觸碰」的是推車 ｜ 推車、布
10. **市民必須服從黃銅書。** ｜ 敘事 ｜ 已喚醒者撕掉它之後……（給敘事收尾用）

## B. 離開、邊界、區域

11. **不得靠近界石。** ｜ `any / approach / boundary / – / forbid` ｜ 沒說不能破壞或搬走界石；界石搬了邊界算哪裡？ ｜ 界石可搬動（★改變範圍判定）
12. **界石不得被搬動。** ｜ `any / move / boundary / – / forbid` ｜ 沒說不能破壞 ｜ 界石 broken 狀態
13. **界石不得被破壞。** ｜ `any / break / boundary` ｜ 沒說不能埋起來／遮住（看不見的界石算不算）｜ 布、土堆
14. **夜間不得走出村道。** ｜ `any / enter / wild★ / night / forbid` ｜ 白天可以；村道「走出」指從路到草地，從草地到草地不算 ｜ 村道格、野地格
15. **不得進入森林。** ｜ `any / enter / forest★` ｜ 森林邊緣算不算；被推進去不算「進入」 ｜ 森林區
16. **不得渡河。** ｜ `any / cross★ / river★` ｜ 沒說不能走橋（橋算不算渡河）；水乾了呢 ｜ 河、橋、水閘
17. **橋在夜間關閉。** ｜ `any / use / bridge★ / night / forbid` ｜ 白天沒管；涉水不是用橋 ｜ 橋、淺灘
18. **外鄉人不得進入市集。** ｜ `outsider / enter / market★` ｜ 穿市民衣服算不算外鄉人（身分判定）｜ 市集區、衣服
19. **不得進入墓地。** ｜ `any / enter / graveyard★` ｜ 墓地圍牆外的路不算；「進入」是走進去，被抬進去不算 ｜ 墓地
20. **任何存在不得登上高塔。** ｜ `any / climb / tower★` ｜ 塔上能看到整個村（範圍、界石）；沒說不能從塔上下來（已在上面的）｜ 高塔、俯瞰視角
21. **不得站在屋頂上。** ｜ `any / climb / house` ｜ 梯子沒被提到；掉下來不算站 ｜ 梯子
22. **外鄉人必須待在廣場。** ｜ `outsider / stay★ / plaza★ / – / require` ｜ 廣場的邊在哪沒定義（底層規則 5：定義不清不追究）｜ 廣場區
23. **不得離開自己的街區。** ｜ `citizen / leave★ / district★` ｜ 只管市民；追捕時追到街區邊界就停 ｜ 街區劃分（村民的活動範圍）
24. **被傳送回中心者，當日不得再靠近邊界。** ｜ `any / approach / boundary / teleported★ / forbid` ｜ 「當日」——過了夜就重算 ｜ 晝夜計數

## C. 門、窗、燈、建築

28. **夜間所有門必須上鎖。** ｜ `citizen / lock★ / door / night / require` ｜ 鑰匙在哪；上鎖的門外鄉人能不能撬 ｜ 鑰匙、鎖
29. **鑰匙不得被取走。** ｜ `any / take / key★` ｜ 「借」算不算取走；請主人帶你進去 ｜ 鑰匙
30. **夜間不得點燈。** ｜ `any / light★ / lamp★ / night / forbid` ｜ 白天點了帶進夜裡（燈沒熄）算不算；火把不是燈 ｜ 燈、火把、持燈狀態
31. **夜間必須持燈行走。** ｜ `any / walk★ / – / night&!lit★ / forbid`（反過來寫）｜ 站著不動不算行走；跟 30 條衝突 → 裁決 ｜ 持燈
32. **燈柱不得被破壞。** ｜ `any / break / lamppost★` ｜ 沒說不能熄滅；沒說不能遮住 ｜ 燈柱（夜間視線範圍）
33. **不得熄滅燈柱。** ｜ `any / extinguish★ / lamppost` ｜ 破壞是另一條；油用完不算熄滅 ｜ 燈油
34. **鐘樓不得被敲響。** ｜ `any / use / bell★` ｜ 鐘自己響（夜晚鐘聲）不算；破壞鐘不是敲 ｜ 鐘（敲響＝全村村民醒來／集合）
35. **夜鐘響後不得外出。** ｜ `any / leave / house / afterbell★ / forbid` ｜ 已經在外面的不算「外出」 ｜ 鐘
36. **不得進入倉庫。** ｜ `any / enter / storehouse★` ｜ 倉庫不是住宅（第 4 條管不到），所以才需要這條；從倉庫拿東西要先進去——請市民拿 ｜ 倉庫
37. **不得開啟井蓋。** ｜ `any / open / well★` ｜ 井蓋壞了就不用開 ｜ 井（井底：藏東西、通道？）
38. **不得使用梯子。** ｜ `any / use / ladder★` ｜ 梯子可以搬去擋路；踩推車不是梯子 ｜ 梯子
39. **建築不得被塗寫。** ｜ `any / deface / house|wall★` ｜ 公告牌不是建築 ｜ 牆面塗鴉（給村民看的訊息？）
40. **任何存在不得在住宅內奔跑。** ｜ `any / run / – / inhouse★ / forbid` ｜ 走路可以 ｜ run 動詞（移動速度兩段）

## D. 廣播、公告、書

41. **廣播器不得被破壞。** ｜ `any / break / speaker` ｜ 沒聽到的人不受約束；壞掉的不會因此修好
42. **廣播器必須被修復。** ｜ `citizen / repair / speaker / broken / require` ｜ 只管市民；修好又壞 ｜ 村民修復行為
43. **外鄉人不得修復廣播器。** ｜ `outsider / repair / speaker` ｜ 沒說不能破壞
44. **廣播器不得被遮蔽。** ｜ `any / cover★ / speaker` ｜ 「遮蔽」是蓋住，站在旁邊擋不算；搬走不是遮蔽 ｜ 布、箱子
45. **廣播器不得被搬動。** ｜ `any / move / speaker` ｜ 推車上的廣播器？ ｜ 可搬動的廣播器（改變覆蓋範圍）
46. **夜間廣播器靜音。** ｜ 系統規則（書寫下＝晚上沒公示）｜ 晚上做的事沒人管——但也沒人聽到新條文
47. **公告牌不得被塗毀。** ｜ `any / deface / notice` ｜ 還是可以讀；沒聽到的不受約束
48. **外鄉人不得閱讀公告牌。** ｜ `outsider / read / notice` ｜ 讀規則書、聽廣播
49. **公告牌必須每日更新。** ｜ `citizen / write★ / notice / day / require` ｜ 更新的是村民，寫什麼他決定？（村民筆跡＝可被塗改）｜ 村民寫公告行為
50. **不得閱讀黃銅書。** ｜ `any / read / book` ｜ 公告牌、廣播
51. **不得靠近黃銅書。** ｜ `outsider / approach / book` ｜ 市民可以搬走它；遠遠地看
52. **黃銅書不得被搬動。** ｜ `any / move / book` ｜ 聽不到廣播的村民會替你搬
53. **黃銅書不得被闔上／翻頁。** ｜ `any / use / book` ｜ 翻頁＝看到舊的被撕條文？ ｜ 書的頁面（歷史）
54. **書台不得被搬動。** ｜ `any / move / lectern` ｜ 書和書台是兩回事
55. **不得在黃銅書前說謊。** ｜ 敘事／`any / talk / book`（誘導在書旁無效？）｜ 「說謊」沒定義（底層規則 5）
56. **市民不得轉述條文給外鄉人。** ｜ `citizen / tell★ / outsider` ｜ 已喚醒者；「轉述」vs 外鄉人自己聽 ｜ 村民可以「告知」規則（第三種公示）

## 從規則反推：需要哪些新東西

**新區域**（地圖變大才有意義）：村道／野地、森林、河＋橋＋淺灘、市集、墓地、田地＋田埂、街區劃分、廣場（已有）。

**新物件**：窗戶、鑰匙＋鎖、燈／火把＋燈油、燈柱、鐘樓、倉庫、井＋水桶、梯子、布／箱子（遮蔽）、食物、衣物＋晾衣繩、工具（鎚、鋸）、樹（可倒）、家畜、崗位、高塔。

**新動詞**（現有 15 個之外）：leave、stay、talk／tell、touch、cross、lock、light／extinguish、cover、hold、wear、eat、trade／receive、invite、follow、wake、gather、noise、report、sleep、harm。不必全做——先挑規則再挑動詞。

**新條件**（cond）：night／day、seen（被看見）、lit（持燈）、wearing（偽裝）、inhouse／outdoor、teleported、afterbell、holding≥N、計時（>60s）、count≥N。

**新機制**：
- 村民視線（距離＋夜間縮短＋燈光延伸）與「看見違規」的追逐觸發。
- 晝夜計時（5 分鐘）、睡眠、鐘。
- 身分判定可被條文改寫（90、108）——這是「規則約束所有存在」最有戲的地方。
- 離開邊界＝傳送回中心（而不是贏）。
- 公告牌由村民更新、村民可轉述條文（第三種公示）。

**我會優先選的 20 條**（給原型三的第一版，覆蓋晝夜、視線、身分、離開）：1、4、5、6、11、14、25、30、31、41、57、64、73、74、81、83、86、96、101、108。理由：每條至少用到一個新機制，而且彼此會衝突（30 vs 31、6 vs 101、83 vs 81、108 vs 86 的漏洞），衝突才會逼書寫裁決。

## 要你決定的

1. 「不得離開」是憲法（會被撕）還是底層（撕不掉）？這決定勝利條件。
2. 追逐觸發：要「被看見」才追，還是違規就全村知道？建議前者，否則夜晚沒意義。
3. 夜間廣播器靜音與否。靜音＝晚上是違規的黃金時段但隔天早上補課一次唸完。
4. 外鄉人要不要有「偽裝」（穿衣服）這條線。有的話，身分判定會變成第二個核心機制。
